状态：Confirmed

## 项目身份

正式名称：**HarnessHub**

英文定位：**Community Marketplace for AI Agent Plugins**

中文定位：**面向 AI Agent 插件生态的社区型市场平台**

HarnessHub 从 DeepSeek Harness 插件生态起步，目标是成为 AI Agent 插件的发现、信任与社区入口。项目不得在没有 Founder 明确决定和公开记录的情况下更改正式名称或核心定位。

## 长期产品原则

HarnessHub 不是：

- 普通 GitHub 插件列表；
- 泛社交平台；
- 黑箱审核平台；
- 强制注册平台。

HarnessHub 是：

- 插件生态入口；
- 用户与开发者社区；
- 开放但可信的平台。

“开放但可信”意味着公开浏览、规则透明、证据可核验、审核可申诉，同时对高风险插件保持必要门槛。

## 原则变更

Founder 可以修改核心原则，但必须：

1. 记录变更内容、理由和生效日期；
2. 不追溯改写历史记录；
3. 对影响用户权利、内容归属或审核规则的重大变更提前公开；
4. 不以原则变更夺取第三方内容的版权。
